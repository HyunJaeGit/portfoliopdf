## Projects

### Aura3D

서버 상태를 주기적으로 확인하고, 상태 변화가 발생했을 때 Gemini API를 이용해 장애 원인을 분석하는 개인 프로젝트입니다.

* Java 21 Virtual Threads 기반 서버 상태 확인
* Spring Boot / JPA / MySQL
* 상태 변화 기반 Gemini API 호출
* 모니터링 이력 관리
* React Three Fiber 기반 3D 상태 표현

### MZ 전국 맛집 정보 플랫폼

전국 음식점 검색과 지도 기능을 구현한 4인 팀 웹 프로젝트입니다.

* Spring MVC / MyBatis
* Oracle Database
* 지역 / 카테고리 기반 검색
* Kakao Map API
* AWS EC2 / RDS / S3
* 팀장으로 일정 및 역할 관리
